Each mode is a single-degree-of-freedom oscillator with its own white-noise force, discretized exactly, so the true frequency and damping are known. Mode k has k half-waves along the girder; all modes have the same response level.

Identification: output covariances up to lag 2s−1 in a block Toeplitz matrix, SVD, system matrix from the shift structure of the observability matrix (Peeters & De Roeck, 1999). Stable poles are grouped into modes by single-linkage clustering on frequency difference + (1 − MAC). Bias is identified minus true damping, averaged over the records run with the current settings.

Python and numpy run in the browser through Pyodide. The SSI code is taken from an operational modal analysis of the Hardanger Bridge (1310 m main span).
